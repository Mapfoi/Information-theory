# Лабораторная работа 3: Эль-Гамаль для файлов произвольного типа

Приложение реализует шифрование и дешифрование **любых файлов** (любого расширения) по алгоритму Эль-Гамаля в режиме WinForms.

## Что делает программа

- Загружает исходный файл как поток байтов.
- Проверяет корректность параметров `p`, `x`, `k`.
- Находит **все первообразные корни** по модулю `p`.
- Показывает их пользователю и позволяет выбрать любой `g` для шифрования.
- Шифрует файл **побайтово**:
  - первый блок шифруется с `k`, введенным пользователем;
  - для каждого следующего блока выбирается случайный `k`, взаимно простой с `p-1`.
- Выводит зашифрованные блоки `(A, B)` на экран в десятичной системе.
- Сохраняет:
  - шифртекст как поток `int32` (`A1, B1, A2, B2, ...`);
  - расшифрованный файл как исходный поток байтов.

## Ограничения на параметры

- `p` — простое число, `p > 255` (чтобы каждый байт `0..255` помещался без потерь).
- `x` — `1 < x < p - 1`.
- `k` — `1 < k < p - 1` и `gcd(k, p-1) = 1`.
- `g` выбирается из найденных первообразных корней по модулю `p`.

## Структура интерфейса

- Поля ввода: `P`, `X`, `K`.
- Кнопка: **Найти все первообразные корни**.
- Список корней `g` (ListBox) + счетчик количества.
- Режимы: **Шифрование / Дешифрование**.
- Кнопки: **Загрузить файл**, **Шифровать**, **Дешифровать**, **Сохранить**, **Очистить**.
- Два текстовых поля:
  - входные данные (байты или пары `A,B`);
  - результат операции (пары `A,B` или байты).

## Основные подпрограммы

### 1) Быстрое возведение в степень по модулю

Используется при вычислениях `g^x mod p`, `g^k mod p`, `y^k mod p` и при дешифровании.

```csharp
private static int FastPowMod(long a, int n, int m)
{
    long res = 1;
    long degreeBase = a;
    long degree = n;

    while (degree != 0)
    {
        while (degree % 2 == 0)
        {
            degree /= 2;
            degreeBase = (degreeBase * degreeBase) % m;
        }

        degree -= 1;
        res = (res * degreeBase) % m;
    }

    return (int)res;
}
```

### 2) Поиск всех первообразных корней по модулю `p`

Алгоритм:
1. Находим уникальные простые делители `p-1`.
2. Число `g` является первообразным, если для каждого делителя `q` выполнено  
   `g^((p-1)/q) mod p != 1`.

```csharp
private static List<int> FindAllPrimitiveRoots(int p)
{
    var uniqPrimeDivisors = GetUniquePrimeDivisors(p - 1);
    var primitiveRoots = new List<int>();
    int j;
    bool flag;

    for (var i = 2; i <= p - 1; i++)
    {
        j = 0;
        flag = true;
        while (flag && j < uniqPrimeDivisors.Count)
        {
            if (FastPowMod(i, (p - 1) / uniqPrimeDivisors[j], p) == 1)
            {
                flag = false;
            }

            j++;
        }

        if (flag)
        {
            primitiveRoots.Add(i);
        }
    }

    return primitiveRoots;
}
```

### 3) Проверки параметров

Параметры валидируются до выполнения шифрования/дешифрования:

- `TryReadPrimeP(...)`
- `TryReadX(...)`
- `TryReadInitialK(...)`
- `TryReadSelectedG(...)`

При ошибке показывается сообщение, операция не запускается.

### 4) Шифрование файла (побайтово)

Открытый ключ: `y = g^x mod p`.  
Для каждого байта `m` вычисляются:

- `A = g^k mod p`
- `B = y^k * m mod p`

```csharp
var y = FastPowMod(g, x, p);
encryptedPairs = new int[sourceBytes.Length * 2];
var index = 0;
var k = initialK;

for (var i = 0; i < sourceBytes.Length; i++)
{
    var a = FastPowMod(g, k, p);
    var b = (int)((long)FastPowMod(y, k, p) * sourceBytes[i] % p);

    encryptedPairs[index++] = a;
    encryptedPairs[index++] = b;

    if (i == 0)
    {
        k = GenerateRandomCoprimeK(p);
    }
    else if (i < sourceBytes.Length - 1)
    {
        k = GenerateRandomCoprimeK(p);
    }
}
```

### 5) Дешифрование

Для пары `(A, B)`:

- `A^{-1} mod p = A^(p-2) mod p` (по малой теореме Ферма)
- `m = B * (A^{-1})^x mod p`

```csharp
var inverseA = FastPowMod(a, p - 2, p);
var plain = (int)((long)FastPowMod(inverseA, x, p) * (b % p) % p);
sourceBytes[outIndex++] = (byte)plain;
```

### 6) Вывод шифртекста в 10-й системе

Результат шифрования выводится на экран как пары:

`[A1, B1] [A2, B2] ...`

Для сохранения в файл каждая компонента записывается как `int32`.

## Формат файлов

- **Исходный/расшифрованный файл**: обычный набор байтов.
- **Зашифрованный файл**: бинарный поток `int32`, где числа идут парами `(A, B)`.

## Запуск

1. Открыть проект `Lab3 ElGamal.csproj` в Visual Studio.
2. Запустить приложение.
3. Ввести `p`, `x`, `k`.
4. Нажать **Найти все первообразные корни** и выбрать `g`.
5. Выбрать режим:
   - **Шифрование**: загрузить исходный файл -> нажать **Шифровать** -> сохранить.
   - **Дешифрование**: загрузить файл шифртекста -> нажать **Дешифровать** -> сохранить.
